**Monte Carlo Stock Price Simulator**

A Python-based Monte Carlo simulation that models potential future stock prices using **Geometric Brownian Motion (GBM)**. The simulator generates multiple possible stock price trajectories based on an initial stock price, expected annual return, and annualized volatility.

## Overview

Monte Carlo simulation is a computational technique that uses repeated random sampling to model possible outcomes of uncertain systems.

This project applies the technique to financial markets by simulating 1,000 possible stock price trajectories over a one-year period. Each simulation incorporates randomly generated market shocks to represent uncertainty in daily stock price movements.

The program visualizes sample price trajectories and calculates summary statistics for the final simulated stock prices.

## Features

- **Geometric Brownian Motion:** Models stock price movements using a continuous-time stochastic process.
- **Multiple Simulations:** Generates 1,000 independent stock price trajectories.
- **Random Market Shocks:** Incorporates normally distributed random variables to represent market uncertainty.
- **Price Visualization:** Plots 50 sample trajectories to illustrate the range of possible outcomes.
- **Statistical Analysis:** Calculates the average, median, maximum, and minimum final stock prices.
- **Automated Output:** Saves the simulation visualization as a PNG file.

## Mathematical Model

The simulator uses the Geometric Brownian Motion model:

[
S\_{t+\Delta t}=S_t e^{(\mu-\frac{1}{2}\sigma^2)\Delta t+\sigma\sqrt{\Delta t}Z}
]

Where:

| Variable   | Description                                   |
| ---------- | --------------------------------------------- |
| (S_t)      | Stock price at the current time               |
| (\mu)      | Expected annual return                        |
| (\sigma)   | Annualized volatility                         |
| (\Delta t) | Time increment                                |
| (Z)        | Standard normally distributed random variable |

Each iteration generates a new random shock, producing a different possible stock price movement.

## Output

### Stock Price Simulation

The simulator generates a visualization containing 50 sample stock price trajectories over 252 trading days.

Each line represents one possible stock price path generated by the stochastic model.

### Statistical Results

After completing the simulations, the program prints:

- **Average Final Price:** Mean of all simulated ending stock prices.
- **Median Final Price:** Middle value of the simulated ending stock prices.
- **Best Case:** Highest simulated ending stock price.
- **Worst Case:** Lowest simulated ending stock price.

The results provide a summary of the range and distribution of potential stock prices under the selected assumptions.

## Limitations

This simulator is an educational implementation of Geometric Brownian Motion and does not predict actual stock market performance.

The model assumes:

- Constant expected returns and volatility throughout the simulation.
- Normally distributed random market shocks.
- Independent price movements between time increments.
- Continuous compounding of returns.
- No transaction costs, dividends, taxes, or external market events.

Actual financial markets may exhibit behaviors that these assumptions do not capture.
